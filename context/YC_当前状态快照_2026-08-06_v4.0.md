## 3. 当前唯一主任务

> 实施Day 3A HumanTask核心，让YC能够持久等待人、记录每次人工提交，并由Worker安全恢复或继续暂停业务流程。

当前执行必须遵守：

1. 复用多角色RBAC，不在Membership增加单一`role`事实源；
2. `HumanTask`与`HumanTaskSubmission`分离；
3. Assignee使用`membership_id`或`role_key`二选一；
4. `KEEP_PAUSED`不创建ResumeSignal和后继任务；
5. Day 3A不使用取消HumanTask隐式终止业务；
6. 人工确认必须标记为人工证据，不冒充平台证据；
7. HTTP只持久化提交和创建Job，Worker应用人工结论。

## 4. Day 3A三条路径

### 人确认已完成

```text
Submission
→ Worker应用
→ 原Attempt仍RESULT_UNKNOWN
→ 原Command确认为SUCCEEDED
→ Run/Step/Track完成
```

### 人确认未执行

```text
Submission
→ 原Command恢复PENDING
→ Run继续
→ 下一次领取生成更高Generation
```

### 继续暂停

```text
Submission记录KEEP_PAUSED
→ HumanTask继续WAITING_USER
→ Run/Step继续WAITING_HUMAN
→ 不创建ResumeSignal
→ 不创建新Generation
```
